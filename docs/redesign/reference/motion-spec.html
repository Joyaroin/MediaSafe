MediaSafe motion

Nothing teleports

Every action turns into its own result. Motion says where something came from, where it went, or whether it worked. It never decorates.

Easing by role

ArriveThings entering or settling. cubic-bezier(0.16, 1, 0.3, 1)
LeaveThings going away, always faster than they came. cubic-bezier(0.25, 1, 0.5, 1)
TravelThings moving from one place to another. cubic-bezier(0.65, 0, 0.35, 1)

Anything under a finger uses a spring instead, so it can follow and reverse: the existing snappy spring for dragging, smooth for settling, bouncy for the tick and the season finish only.

Guardrails

  • Animate transform and opacity only. The prototype animates width and height for simplicity; production should not.
  • No more than two things move at once.
  • A response starts within 100 ms of the touch, before the server answers.
  • Every moment has a still version, listed above.
  • Tapping always works. Gestures are shortcuts, never the only way.
  • Test on the real phone with the processor slowed four times.
