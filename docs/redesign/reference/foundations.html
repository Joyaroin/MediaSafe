Emphasis without colour

  1. Filled: the one main action on a screen, and the tick for a recorded watch.
  2. Outlined: whatever is currently selected.
  3. Plain or dim: everything else.

Fill and outline both use the text colour. The only colours in the product are artwork and danger.

Title tint

Borrowed from each poster and set to one fixed depth, so text keeps its contrast. It fills the hero and artwork placeholders, never a control. The Title tint board has the rule.
